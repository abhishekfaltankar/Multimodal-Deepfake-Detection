# Multimodal Deepfake Detection

A deep learning-based system for detecting deepfake videos using computer vision and audio analysis.

## Features

- Video frame extraction
- Face detection
- Pretrained deep learning model
- Real/Fake classification
- Streamlit web application

## Tech Stack

- Python
- OpenCV
- PyTorch
- MediaPipe
- Streamlit
- NumPy
- Pandas

## Dataset

- Celeb-DF (v2)
